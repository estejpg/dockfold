# Icon sources

Every demo app image was downloaded as a complete `.icns` file from macOSicons with `wget`, then converted from its largest representation to a 512 × 512 PNG. The original files are retained in `assets/icns/original/`; the web-ready conversions live in `public/app-icons/`.
